# 문제 해결 기록

| 현상 | 원인 또는 확인된 조건 | 조치 |
|---|---|---|
| Ubuntu 설치 USB 생성 실패 | balenaEtcher 작업 오류 | Mac에서 `dd`로 USB 생성 |
| 설치 중 Wi-Fi 연결 지연 | DHCP 및 무선 인터페이스 설정 문제 | 설치 후 Netplan 구성 |
| 원격 SSH 타임아웃 | Mac에서 NordVPN 활성화 시 재현 | NordVPN 비활성화 후 접속 성공 |
| systemd `203/EXEC` | 서비스에 지정한 스크립트 파일 누락 | 파일 생성 및 실행 권한 설정 |

민감한 로그나 실제 인증 정보는 공개 저장소에 업로드하지 않는다.
